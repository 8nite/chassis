title: "Commands"
description: "Reference for the chassis command line."
---

Every command accepts `--help` for its full flag list, for example `chassis run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ chassis run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Chassis review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: bun install
      - run: bun run --cwd packages/cli src/index.ts run --standalone --model anthropic/claude-sonnet-4-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ chassis run --model anthropic/claude-sonnet-4-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ chassis run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ chassis run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ chassis run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ chassis run --agent build "Fix the failing test"
```

View all subcommands and flags.

```bash
$ chassis run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ chassis mini
```

Continue the last session.

```bash
$ chassis mini --continue
```

Start with a model and an initial prompt.

```bash
$ chassis mini --model anthropic/claude-sonnet-4-5 --prompt "Summarize this repository"
```

View all subcommands and flags.

```bash
$ chassis mini --help
```

## session

Manages sessions.

```bash
$ chassis session list
```

Limit the list and print JSON.

```bash
$ chassis session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ chassis session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ chassis session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ chassis session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ chassis session import session.json
```

Import into a specific directory.

```bash
$ chassis session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ chassis session --help
```

## auth

Manages AI providers and credentials.

```bash
$ chassis auth list
```

List them as JSON.

```bash
$ chassis auth list --format json
```

Log in to a provider.

```bash
$ chassis auth login anthropic
```

Log in with a specific authentication method.

```bash
$ chassis auth login anthropic --method key
```

Log out of a saved account.

```bash
$ chassis auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ chassis auth switch anthropic work
```

View all subcommands and flags.

```bash
$ chassis auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ chassis mcp list
```

Add a remote server.

```bash
$ chassis mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ chassis mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ chassis mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ chassis mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ chassis mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ chassis mcp logout sentry
```

View all subcommands and flags.

```bash
$ chassis mcp --help
```

## plugin

Manages plugins.

```bash
$ chassis plugin list
```

Include built-in server plugins.

```bash
$ chassis plugin list --builtin
```

Install a plugin and add it to the global configuration.

```bash
$ chassis plugin add @example/chassis-tui
```

Check package plugins for updates.

```bash
$ chassis plugin check
```

Update package plugins.

```bash
$ chassis plugin update
```

Remove a plugin from global configuration.

```bash
$ chassis plugin remove @example/chassis-tui
```

View all subcommands and flags.

```bash
$ chassis plugin --help
```

## stats

Shows shareable usage statistics.

```bash
$ chassis stats
```

Show the last 7 days.

```bash
$ chassis stats --days 7
```

Show model usage.

```bash
$ chassis stats --models
```

Show cost and token details.

```bash
$ chassis stats --cost
```

Print JSON instead of a report.

```bash
$ chassis stats --json
```

View all subcommands and flags.

```bash
$ chassis stats --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ chassis serve
```

Bind to all interfaces on a fixed port.

```bash
$ chassis serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ chassis serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ chassis serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ chassis pair
```

Use an external URL in the links.

```bash
$ chassis pair --url https://dev.example.com
```

View all subcommands and flags.

```bash
$ chassis pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ chassis service start
```

Restart it.

```bash
$ chassis service restart
```

Show its status.

```bash
$ chassis service status
```

Stop it.

```bash
$ chassis service stop
```

Read a setting.

```bash
$ chassis service get hostname
```

Set a setting.

```bash
$ chassis service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ chassis service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ chassis service set env CHASSIS_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ chassis service unset hostname
```

View all subcommands and flags.

```bash
$ chassis service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ chassis reload
```

## api

Makes a request to the running server.

```bash
$ chassis api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ chassis api session.list --param limit=10
```

Send a JSON body.

```bash
$ chassis api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ chassis api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ chassis api --help
```
